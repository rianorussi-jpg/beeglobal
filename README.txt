BEE GLOBAL FOOD — FORMULARIO A TELEGRAM

1. Sube esta carpeta como proyecto a Vercel.
2. En Vercel > Project > Settings > Environment Variables agrega:
   TELEGRAM_BOT_TOKEN = el token NUEVO de tu bot
   TELEGRAM_CHAT_IDS = 6366835513,7681123167
3. Guarda y haz Redeploy.
4. Ambos chats deben haber iniciado el bot con /start al menos una vez.
5. Prueba el formulario desde el dominio desplegado (no abriendo index.html directamente como archivo local).

IMPORTANTE: nunca pongas TELEGRAM_BOT_TOKEN dentro de index.html.
